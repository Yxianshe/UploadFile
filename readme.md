# SFTP Pro - 文件传输工具

一款基于 Python 和 Tkinter 开发的现代化 SFTP 文件上传/下载工具。

## 功能特性

### 连接方式

该工具支持三种连接方式：

#### 1. 直接连接服务器
- 不启用跳板机功能
- 直接建立 SSH 连接到目标服务器
- 支持密码认证、密钥认证

#### 2. 通过跳板机连接服务器
- 勾选"启用转发"选项
- 先连接到跳板机（Jump Host）
- 通过 SSH 隧道连接到目标服务器
- 支持跳板机和目标服务器的独立认证配置

#### 3. 通过跳板机连接集群
- 支持交互式认证（MFA）
- 自动识别并处理 PortalPIN 输入
- 支持动态验证码弹窗输入
- 智能匹配密码/PIN 输入

### 传输功能

- 📤 **上传**：支持单文件或文件夹上传
- 📥 **下载**：自动识别远程路径是文件还是文件夹
- ⚡ **断点续传**：支持跳过已存在的同名同大小文件
- 📊 **实时进度**：显示传输进度、速度和当前文件

### 高级特性

- ✅ **强制覆盖**：可选择是否跳过已存在的文件
- 📐 **文件大小计算**：可选是否预先计算文件总大小
- 💾 **配置管理**：保存连接配置到历史记录
- 🖥️ **交互式终端**：支持执行远程命令
- 🎨 **现代 UI**：深色主题，美观的按钮和进度条

## 使用说明

### 1. 配置连接

**目标服务器配置：**
- IP 地址：目标服务器的 IP 或域名
- 用户名：SSH 登录用户名
- 密钥 Key（选填）：私钥文件路径，默认 `~/.ssh/id_rsa`
- 密码：普通服务器密码
- PortalPIN（集群）：集群环境的 PIN 码

**跳板机配置（可选）：**
- 勾选"启用转发"启用跳板机功能
- 填写跳板机的 IP、用户名、密钥和密码

### 2. 上传文件

1. 选择"上传"标签页
2. 选择上传模式：单文件或文件夹
3. 设置本地源路径和远程目标目录
4. 点击"🔗 连接服务器"建立连接
5. 点击"▶ 开始上传"开始传输

### 3. 下载文件

1. 选择"下载"标签页
2. 设置远程源路径和本地保存目录
3. 点击"🔗 连接服务器"建立连接
4. 点击"▼ 开始下载"开始传输

### 4. 终端命令

在底部终端输入框中输入命令，按回车或点击"发送指令"执行远程命令。

## 技术栈

- **Python 3.x**
- **Tkinter** - GUI 框架
- **Paramiko** - SSH/SFTP 库

## 配置文件

连接历史记录保存在：`~/.sftp_uploader_history.json`
